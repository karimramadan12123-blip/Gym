# QR Code Gym (PWA)

تطبيق ويب تقدمي (PWA) لعرض كارت العضوية، يعمل بدون إنترنت بعد أول فتح.

## التشغيل على الكمبيوتر للتجربة
    python3 -m http.server 8080
ثم افتح http://localhost:8080

## التثبيت على الهاتف
يجب رفع مجلد المشروع على استضافة HTTPS (مجانية مثل GitHub Pages أو Netlify أو Cloudflare Pages).
1. افتح رابط الموقع على الهاتف مرة واحدة وهو متصل بالإنترنت.
2. أندرويد (Chrome): القائمة ⋮ ← «تثبيت التطبيق» / «Add to Home screen».
   آيفون (Safari): زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
3. بعد ذلك يعمل التطبيق بدون إنترنت.

## الملفات
- index.html / style.css / app.js : الواجهة والمنطق
- default-card.jpg : الكارت الافتراضي (يمكن استبداله بصورة أوضح بنفس الاسم)
- sw.js : العمل بدون إنترنت
- manifest.webmanifest + icons/ : التثبيت والأيقونات

عند تغيير أي ملف بعد النشر، غيّر رقم CACHE في sw.js (مثل v2) ليصل التحديث للمستخدمين.
